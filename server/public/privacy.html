1. Introdução

Esta Política de Privacidade descreve como o AS IPTV Player ("nós", "nosso" ou "aplicativo"), desenvolvido por Adriano Sena, coleta, armazena, utiliza e protege as informações dos usuários ("você") em conformidade com a Lei Geral de Proteção de Dados (LGPD — Lei nº 13.709/2018) e demais normas aplicáveis.

Ao instalar e utilizar o AS IPTV Player, você concorda com os termos desta política. Se não concordar com algum ponto, recomendamos que encerre o uso do aplicativo.

O AS IPTV Player é um player de mídia local. Não somos um provedor de conteúdo IPTV. O usuário é responsável pela procedência do conteúdo acessado por meio do seu servidor Xtream particular.

2. Dados que Coletamos

Coletamos o mínimo necessário para o funcionamento do app e melhoria dos nossos serviços.

2.1 Dados fornecidos por você

  • E-mail e senha para criação de conta na plataforma;
  • Nome de exibição e foto de perfil (opcionais);
  • Credenciais do servidor Xtream Codes (URL, usuário e senha do seu servidor IPTV particular);
  • Informações de pagamento de planos premium (processadas por gateway de pagamento — não armazenamos dados de cartão).

2.2 Dados gerados automaticamente pelo app

  • Histórico de visualização (título, posição, data) — armazenado localmente no dispositivo;
  • Preferências e gostos derivados do algoritmo de recomendação — processados exclusivamente no dispositivo;
  • Configurações do app (tema, idioma, perfis) — armazenadas localmente;
  • Logs de erro anônimos para diagnóstico de falhas (sem identificação pessoal).

2.3 Dados que não coletamos

  • Conteúdo do catálogo ou dos streams — ficam no seu dispositivo;
  • Dados de localização geográfica;
  • Contatos do dispositivo;
  • Dados de outros aplicativos instalados;
  • Dados biométricos ou de câmera.

3. Finalidade do Uso dos Dados

Seus dados são utilizados exclusivamente para:

  1. Autenticação: Identificar você na plataforma e permitir login seguro.
  2. Gestão de assinatura: Verificar o plano ativo e liberar os recursos correspondentes.
  3. Sincronização opcional: Se habilitado, sincronizar listas e progresso entre dispositivos.
  4. Diagnóstico de erros: Logs anônimos para identificar e corrigir falhas técnicas.
  5. Comunicação: Enviar notificações de atualizações, renovação de plano ou suporte (com opt-out disponível).
  6. Segurança: Detectar acesso não autorizado à conta.
Seus dados jamais serão utilizados para publicidade comportamental, venda a terceiros ou análise de perfil fora das finalidades descritas acima.

4. Armazenamento dos Dados

4.1 Dados locais (no dispositivo)

A maior parte dos dados gerados pelo app — incluindo catálogo sincronizado, histórico de visualização, recomendações e preferências — é armazenada exclusivamente no seu dispositivo através de banco de dados local (SQLite). Esses dados não são transmitidos a servidores externos automaticamente.

4.2 Dados em nuvem

Apenas as informações necessárias para autenticação e gerenciamento de conta são armazenadas em servidores seguros, com infraestrutura hospedada no Brasil ou em conformidade com as exigências da LGPD.

4.3 Credenciais do servidor IPTV

As credenciais do seu servidor Xtream são armazenadas de forma criptografada no dispositivo e transmitidas apenas para o servidor informado por você. Nunca são enviadas para servidores do desenvolvedor.

Todas as transmissões entre app e servidores utilizam HTTPS com criptografia TLS 1.2+. Dados sensíveis em repouso são criptografados com AES-256.

5. Compartilhamento de Dados

Seus dados pessoais não são vendidos, alugados ou negociados com terceiros.

O compartilhamento ocorre apenas nas seguintes situações:

  • Gateway de pagamento: Os dados de pagamento são processados por provedor certificado PCI-DSS. Não armazenamos dados de cartão de crédito.
  • Obrigação legal: Quando exigido por lei, ordem judicial ou autoridade competente.
  • Proteção de direitos: Para prevenir fraudes ou violações dos Termos de Uso.
  • Operações societárias: Em caso de fusão, aquisição ou transferência de ativos, com notificação prévia.

7. Crianças e Adolescentes

O AS IPTV Player não se destina a crianças menores de 12 anos. Não coletamos intencionalmente dados de crianças sem consentimento parental verificável.

O plano Ultra e o plano Lifetime incluem recursos de controle parental e monitor em tempo real especificamente para que responsáveis supervisionem e protejam crianças no uso do aplicativo.

Se você é responsável por uma criança e descobrir que ela criou uma conta sem autorização, entre em contato conosco pelo e-mail abaixo para exclusão imediata dos dados.

Usuários entre 12 e 18 anos devem ter consentimento de um responsável para criar conta e realizar pagamentos.

9. Segurança dos Dados

Adotamos medidas técnicas e organizacionais para proteger seus dados, incluindo:

  • Transmissão de dados via HTTPS / TLS 1.2+;
  • Armazenamento de senhas com hash bcrypt — nunca em texto puro;
  • Criptografia AES-256 para dados sensíveis em repouso;
  • Acesso restrito a dados pessoais apenas para equipe essencial;
  • Monitoramento de acessos suspeitos e logs de auditoria;
  • Atualizações regulares de segurança aplicadas ao app e infraestrutura.
Em caso de incidente de segurança que afete seus dados, notificaremos você e a ANPD no prazo legal de 72 horas após a ciência do fato.

10. Retenção de Dados

Seus dados são mantidos apenas pelo tempo necessário às finalidades descritas:

  • Dados da conta: Mantidos enquanto a conta estiver ativa. Excluídos em até 30 dias após solicitação de exclusão.
  • Dados de pagamento: Mantidos pelo período exigido por obrigação fiscal e legal (até 5 anos).
  • Logs de erro anônimos: Mantidos por até 12 meses para análise de qualidade.
  • Histórico e preferências locais: Ficam no dispositivo e são excluídos quando o app é desinstalado ou ao limpar dados do app.

11. Alterações nesta Política

Esta política pode ser atualizada periodicamente para refletir mudanças no app, na legislação ou nas nossas práticas. Quando isso ocorrer:

  • A data de "Última atualização" no topo desta página será revisada;
  • Alterações relevantes serão comunicadas via notificação no app ou por e-mail;
  • O uso continuado do app após a notificação implica aceite das alterações.

Recomendamos revisar esta página periodicamente para se manter informado.
